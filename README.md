# Minitask

Membuat program untuk menampilkan list email dalam bentuk array yang datanya diambil menggunakaan fetch() dari [jsonplaceholder.com](https://jsonplaceholder.typicode.com/users).

Kemudian selain meng-outputkan list email pastikan email dalam bentuk lower case yang mana metode yang digunakan di buat 2 versi, versi dengan built-in method dan tanpa built-in method.

Dalam program ini versi dengan built-in method menggunakan method `.toLowerCase()`, sedangkan versi tanpa built-in method menggunakan perulangan dan if statement yang masing-masing huruf di looping dan di cocokkan dengan dictionary alphabet yang disimpan dalam bentuk object.
